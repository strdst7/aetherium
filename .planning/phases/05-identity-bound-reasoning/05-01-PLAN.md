<objective>
Create the IdentityBindingService that resolves identity_anchor strings to full SigilIdentity objects before reasoning begins. This is the foundation for all identity-bound reasoning.

Purpose: Every reasoning request includes an identity_anchor. This service resolves that anchor to a full identity definition, enabling downstream components to apply identity rules.
Output: IdentityBindingService with caching, latency tracking, and error handling.
</objective>

1. Create `api/src/services/identity-binding.ts` with:
   - `IdentityBindingService` class that accepts `IdentityService` in constructor
   - `resolve(identity_anchor: string)` method that:
     - Returns `SigilIdentity | null` (null if identity not found)
     - Measures lookup time (start → end)
     - Logs latency warning if >200ms
   - `resolveOrThrow(identity_anchor: string)` that throws `AetheriumError` with `IDENTITY_NOT_FOUND` if not found

   - Test: cache returns same identity without calling service again
   - Test: cache expires after TTL
   - Test: latency is measured and logged
