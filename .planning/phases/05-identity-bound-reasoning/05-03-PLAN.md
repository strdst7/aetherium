<objective>
Enforce identity-scoped memory retrieval so that an identity only sees its own memory shards. No cross-identity leakage.

Purpose: The memory service currently retrieves globally. This plan adds identity scoping to memory queries so that memories are filtered by the active identity.
Output: Identity-scoped memory retrieval with tests proving no cross-identity leakage.
</objective>

1. Update `MemoryService.vectorSearch()` to accept optional `identity_anchor?: string` parameter:
   - If identity_anchor provided, add filter: `{ sigil: identity_anchor }` to the query
   - If not provided, query all memories (backward compatible)
   - Update `vectorSearch` signature: `vectorSearch(embedding: number[], alpha: number, k: number, identity_anchor?: string)`

   - Test: Two different identities don't see each other's memories
