  <action>
Create `api/src/services/audit-service.ts` with `AuditService` class:

1. Constructor:
   - Accepts optional MongoDB URI or uses process.env.MONGODB_URI
   - Stores db instance (type: any / Db from mongodb driver)
   - Collection name: `audit_records`

2. `async connect(uri?: string): Promise<void>`:
   - Connect to MongoDB using MongoClient (same pattern as IdentityService)
   - Store db reference
   - Call `ensureIndexes()` after connection

3. `async save(record: AuditRecordCreate): Promise<AuditRecord>`:
   - Generate recordId: `uuidv4()` (use crypto.randomUUID or uuid package)
   - Generate timestamp: `new Date().toISOString()`
   - Generate hash: `generateHash(record)`
   - Construct full AuditRecord
   - Insert into MongoDB collection via `insertOne`
   - Return the saved AuditRecord
   - If insert fails, log warning but don't throw (best-effort)

4. `async query(query: AuditQuery): Promise<AuditListResponse>`:
   - Build MongoDB filter:
     ```typescript
     const filter: any = { identityId: query.identityId };
     if (query.from || query.to) {
       filter.timestamp = {};
       if (query.from) filter.timestamp.$gte = query.from;
       if (query.to) filter.timestamp.$lte = query.to;
     }
     ```
   - Count total: `collection.countDocuments(filter)`
   - Set defaults: limit = Math.min(query.limit || 50, 500), offset = query.offset || 0
   - Sort: `query.sort === 'asc' ? 1 : -1` on timestamp
   - Execute query: `collection.find(filter).sort({ timestamp: sort }).limit(limit).skip(offset).toArray()`
   - Return AuditListResponse with records and pagination

5. `generateHash(record: AuditRecordCreate): string`:
   - Create canonical string: `${record.identityId}|${record.identityVersion}|${record.prompt}|${record.output}|${record.provenance.providerName}`
   - Use Node.js crypto.createHash('sha256').update(canonical).digest('hex')
   - Return the hash string

6. `async ensureIndexes(): Promise<void>`:
   - Create index on `identityId` (for filtering)
   - Create index on `timestamp` (for sorting and date range queries)
   - Create compound index on `{ identityId: 1, timestamp: -1 }` (for efficient filtered queries)
   - Use `createIndex` with `background: true`

7. Export `AUDIT_COLLECTION_NAME = 'audit_records'` constant.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Generation pipeline → AuditService.save() | Audit capture is best-effort; failures don't block generation |
| AuditService → MongoDB | Audit data is persisted; tamper detection via hash |
| AuditQuery → AuditService.query() | Query parameters filter what data is returned |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03 | Tampering | AuditRecord.hash | accept | Hash is advisory; immutability enforced by API design (no update/delete endpoints) |
| T-08-04 | Denial of Service | Large limit param | mitigate | Max limit 500 enforced; pagination prevents unbounded queries |
| T-08-05 | Information Disclosure | Audit record contents | accept | Audit data is user-generated; privacy is a data classification concern |
| T-08-06 | Elevation of Privilege | Query any identity | accept | Single-tenant for v1; authorization is a future enhancement |
</threat_model>
