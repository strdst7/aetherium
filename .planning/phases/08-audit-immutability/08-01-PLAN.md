<task type="auto">
  <name>task 1: create Audit type definitions</name>
  <files>api/src/types/audit.ts, api/src/types/audit.test.ts</files>
  <action>
Create `api/src/types/audit.ts` with the following type definitions (use TypeScript interfaces, export all):

1. `AuditProvenance` — chain of generation transformations:
   - `originalOutput: string` — the raw LLM output before any transformation
   - `mythifyTransformations?: string[]` — transformations applied by MythicModule
   - `validationReport?: ValidationReport` — validation results from Sovereign Halo
   - `regenerationAttempts?: number` — number of regeneration attempts
   - `memoryShards?: Array<{ id: string; excerpt: string; score: number }>` — memories used
   - `providerName: string` — which provider generated the output
   - `modelVersion?: string` — model identifier

2. `AuditRecord` — the immutable audit record:
   - `recordId: string` — UUID v4 for unique identification
   - `identityId: string` — the identity this generation was for
   - `identityName: string` — human-readable identity name
   - `identityVersion: number` — identity version at time of generation
   - `prompt: string` — the full prompt sent to the LLM
   - `output: string` — the final output delivered to the user
   - `reasoningTrace?: any` — the reasoning trace from the generation
   - `validationReport?: ValidationReport` — validation report if validation was performed
   - `provenance: AuditProvenance` — generation chain details
   - `timestamp: string` — ISO 8601 timestamp with millisecond precision
   - `hash: string` — SHA-256 hash of key fields for tamper detection
   - `metadata?: Record<string, any>` — optional extra metadata

3. `AuditRecordCreate` — input for creating an audit record (omits auto-generated fields):
   - Same as AuditRecord but without `recordId`, `timestamp`, `hash`

4. `AuditQuery` — query parameters for audit searches:
   - `identityId: string` — required identity filter
   - `from?: string` — ISO 8601 start date
   - `to?: string` — ISO 8601 end date
   - `limit?: number` — max records to return (default 50, max 500)
   - `offset?: number` — pagination offset (default 0)
   - `sort?: 'asc' | 'desc'` — sort order (default 'desc')

5. `AuditPagination` — pagination metadata in responses:
   - `total: number` — total matching records
   - `limit: number` — records per page
   - `offset: number` — current offset
   - `hasMore: boolean` — whether more records exist

6. `AuditListResponse` — response structure for audit queries:
   - `records: AuditRecord[]`
   - `pagination: AuditPagination`
   - `apiVersion: string`

Also create `api/src/types/audit.test.ts` with:
   - Test that a valid AuditRecord can be constructed with all fields
   - Test that AuditRecord hash is non-empty
   - Test that AuditQuery defaults are sensible
   - Test that AuditPagination calculates hasMore correctly
   - Test that AuditRecordCreate omits auto-generated fields
