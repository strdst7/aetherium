   ```typescript
   private async saveAuditRecord(
     req: OrchestratorRequest,
     response: OrchestratorResponse,
     identity: SigilIdentity | null,
     provider: any
   ): Promise<void>
   ```
   Implementation:
   - If `auditService` is undefined OR `identity` is null → return immediately (skip audit)
   - Build `AuditRecordCreate`:
     ```typescript
     const auditRecord: AuditRecordCreate = {
       identityId: identity.id,
       identityName: identity.name,
       identityVersion: identity.version,
       prompt: response.context.fullPrompt,
       output: response.text,
       reasoningTrace: response.reflectiveResult,
       validationReport: response.validationReport,
       provenance: {
         originalOutput: response.text,
         providerName: response.context.selectedProvider,
         modelVersion: provider.model || 'unknown',
         mythifyTransformations: [], // Populated if mythicModule applied
         regenerationAttempts: response.validationReport?.attemptNumber,
         memoryShards: response.context.relevantMemories.map((m: any) => ({
           id: m.doc?.id || 'unknown',
           excerpt: m.doc?.content?.substring(0, 200) || '',
           score: m.score,
         })),
       },
       metadata: {
         processingTimeMs: Date.now() - startTime,
         apiVersion: CURRENT_API_VERSION,
       },
     };
     ```
   - Call `this.auditService.save(auditRecord)`
   - Wrap in try/catch: if save fails, log warning but don't throw (best-effort)

   - Pass the response object (before returning it)

   - Add timing
   - Call `saveAuditRecord()` after final response is built

5. Update the legacy `orchestrateReasoning()` function:
   - Pass `auditService` if available (but since this is a legacy static function, it may not have access — document this limitation)

6. Ensure all existing code paths remain intact:
   - The `refinedCandidate` field still works
   - `context` object stays the same
   - Memory retrieval, embedding, identity loading all remain unchanged
   - When `auditService` is undefined, behavior is identical to Phase 7
