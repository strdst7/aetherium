Create `api/src/controllers/audit.ts`:

1. `AuditController` class:
   - Constructor: `constructor(private auditService: AuditService)`
   - `async getAuditRecords(req: Request, res: Response): Promise<void>`:
     - Extract query params: `identity_id`, `from`, `to`, `limit`, `offset`, `sort`
     - Validate: `identity_id` is required (return 400 Problem Details if missing)
     - Validate: `from` and `to` are valid ISO 8601 dates if provided (return 400 if invalid)
     - Validate: `limit` is a number between 1 and 500 (return 400 if invalid)
     - Validate: `offset` is a non-negative number (return 400 if invalid)
     - Validate: `sort` is either 'asc' or 'desc' (default 'desc')
     - Build AuditQuery object:
       ```typescript
       const query: AuditQuery = {
         identityId: req.query.identity_id as string,
         from: req.query.from as string | undefined,
         to: req.query.to as string | undefined,
         limit: req.query.limit ? parseInt(req.query.limit as string, 10) : undefined,
         offset: req.query.offset ? parseInt(req.query.offset as string, 10) : undefined,
         sort: (req.query.sort as 'asc' | 'desc') || 'desc',
       };
       ```
     - Call `this.auditService.query(query)`
     - Return JSON response with `records` and `pagination`
     - Add `apiVersion` from CURRENT_API_VERSION
