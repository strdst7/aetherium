  <action>
    Update the `handleReason` method in `ReasonController` to support mode routing:

    1. **Add mode detection method**:
       ```typescript
       private detectMode(req: ReasonRequest): "tool" | "task" {
         // Explicit mode override
         if (req.options?.mode === "tool" || req.options?.mode === "task") {
           return req.options.mode;
         }
         
         // Auto-detection heuristic per D-26
         const queryText = req.messages.map((m) => m.content).join(" ");
         const taskKeywords = ["and then", "after that", "first then", "first, then", "step by step", "plan to", "workflow", "multi-step"];
         const hasTaskKeywords = taskKeywords.some((keyword) => queryText.toLowerCase().includes(keyword));
         
         if (hasTaskKeywords) {
           return "task";
         }
         
         // Default to tool mode for simple queries
         return "tool";
       }
       ```

    2. **Update the tool execution branch** in `handleReason`:
       - Currently: if `req.options?.enableTools && this.agentBuilder`, call `agentBuilder.execute`
       - New: Determine mode using `detectMode(req)`
       - If mode is `"task"`: call `this.agentBuilder.executeTask(req, { enableTools: true, maxTaskIterations: 20 })`
       - If mode is `"tool"`: call `this.agentBuilder.execute(req, { enableTools: true, maxToolIterations: 5 })`
       - Update the `orchestratorResponse` construction for task mode to include `plan`, `actions`, and `planStatus` from the agent result
