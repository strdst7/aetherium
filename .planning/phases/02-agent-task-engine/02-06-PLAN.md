### Integration Test Scenario
1. Seed demo data into MongoDB
2. Submit request: "Find all users who haven't logged in for 30 days and set their status to inactive"
3. Agent generates plan:
   - Step 1: query users with lastLogin < 30 days ago
   - Step 2: update status to inactive for those users
4. Agent executes plan
5. Response includes:
   - `plan` with 2 steps
   - `actions` with `report` (query results) and `update` (update count)
   - `planStatus: "complete"`
   - `output` summarizing the action taken
