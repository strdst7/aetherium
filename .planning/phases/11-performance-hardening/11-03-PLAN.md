  <action>
    Create `api/src/tests/performance/concurrency.test.ts` with the following tests:

    1. **Test setup** (beforeAll):
       - Connect IdentityService, MemoryService, AuditService to global.testDb.uri
       - Initialize ProviderRegistry, IdentityBindingService, SymbolicAnchorLoader, MythicModule, IdentityConstraintEngine, SovereignHaloService
       - Register MockProviderFactory with deterministic=true
       - Create Orchestrator with all services

    2. **Test teardown** (afterAll):
       - Disconnect all services and clear ProviderRegistry

    3. **"should handle concurrent requests for different identities without memory leakage"**:
       - Create 3 distinct identities (A, B, C)
       - Insert a memory shard for identity A only (using memoryService.upsertMemory with identityA.id)
       - Fire 3 concurrent Orchestrator.process() requests, one for each identity, all with prompt "What do you know?"
       - Use Promise.all to wait for all three
       - Assert: response for identity A contains the memory shard in relevantMemories
       - Assert: responses for identities B and C have relevantMemories equal to [] (no leakage)
       - Assert: each response has the correct identity field matching the requested identity

    4. **"should handle concurrent requests with identity-bound constraints without contamination"**:
       - Create identity A with customRules: ["must not contain: jargon"]
       - Create identity B with customRules: ["must not contain: slang"]
       - Register mock provider that returns text containing both "jargon" and "slang"
       - Fire 2 concurrent requests for A and B
       - Assert: response for A has validationReport.status === "failed" (caught jargon violation)
       - Assert: response for B has validationReport.status === "failed" (caught slang violation)
       - Assert: neither identity's constraint leaked to the other (A did not fail on slang, B did not fail on jargon)

    5. **"should maintain audit record isolation under concurrent load"**:
       - Create 2 identities (A, B)
       - Fire 2 concurrent generation requests
       - Query audit records for identity A
       - Query audit records for identity B
       - Assert: audit records for A all have identityId === A.id
       - Assert: audit records for B all have identityId === B.id
       - Assert: no audit record for A contains B's identityId

    6. **"should complete all concurrent requests without errors under moderate load"**:
       - Use DEFAULT_CONCURRENCY_SCENARIO (5 identities, 10 requests, concurrentCount 5)
       - Fire all requests with Promise.all (or chunk into concurrentCount batches if needed)
       - Assert: all responses have status ok (no exceptions thrown)
       - Assert: all responses have text property with length > 0
       - Use BenchmarkRunner to measure total elapsed time for the batch
       - Log benchmark.summary()
  </action>
