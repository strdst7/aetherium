<interfaces>
From design/sigil/v1.json:
- `geometry.aspect_ratios` → ratio anchors (golden: 1.618:1, sigil_core: 1:1.414)
- `geometry.scale` → archetype anchors (size scale values)
- `colors.primary`, `colors.accent` → color anchors (hex values)
- `motion.easing.sigil_pulse` → motion anchor (cubic-bezier)
- `sigil.compliance_rules` → narrative constraints (rule descriptions with weights)

From api/src/types/mythic.ts:
```typescript
export interface SymbolicAnchor {
  type: 'geometry' | 'color' | 'ratio' | 'archetype' | 'motion';
  name: string;
  value: string | number | Record<string, any>;
  weight: number;
  description?: string;
}
```
</interfaces>

Create `api/src/services/symbolic-anchor-loader.ts` with:

1. `SymbolicAnchorLoader` class:
   - `constructor(designSystemPath?: string)` — defaults to `../../design/sigil/v1.json` relative to the service file (use path.join with __dirname)
   - `loadAnchors(): SymbolicAnchor[]` — reads and parses v1.json, returns array of SymbolicAnchor objects

2. Extraction rules (map v1.json sections to SymbolicAnchor):
   - `geometry.aspect_ratios` → type: 'ratio', name: key, value: ratio string, weight: 0.9
   - `geometry.scale` → type: 'archetype', name: key, value: number, weight: 0.6
   - `colors.primary` & `colors.accent` → type: 'color', name: `${palette}_${shade}`, value: hex, weight: 0.7 for primary, 0.5 for accent
   - `motion.easing.sigil_pulse` → type: 'motion', name: 'sigil_pulse', value: cubic-bezier string, weight: 0.8
   - `sigil.compliance_rules` → type: 'archetype', name: rule.rule, value: { description: rule.description, weight: rule.weight }, weight: rule.weight

3. `loadConstraints(): NarrativeConstraint[]` — extracts compliance_rules as narrative constraints:
   - constraint: rule.description
   - scope: map "must" rules to 'throughout', "animation" to 'transition', others to 'opening'
   - severity: map weight >= 0.8 to 'imperative', >= 0.5 to 'requirement', else 'suggestion'

4. Error handling:
   - If v1.json missing or unreadable → log warning, return empty arrays
   - If JSON parse fails → log error, return empty arrays
   - If expected keys missing → skip gracefully, log debug message

5. Helper method `getAnchorByName(name: string): SymbolicAnchor | undefined` for lookup by name
