<task type="auto">
  <name>task 1: create Mythic Module type definitions</name>
  <files>api/src/types/mythic.ts, api/src/types/mythic.test.ts</files>
  <action>
Create `api/src/types/mythic.ts` with the following type definitions (use TypeScript interfaces, export all):

1. `ToneModel` — describes the emotional register of an identity:
   - `formality: 'casual' | 'neutral' | 'formal' | 'ceremonial'`
   - `emotionalRange: 'stoic' | 'measured' | 'expressive' | 'passionate'`
   - `directness: 'indirect' | 'balanced' | 'direct' | 'blunt'`
   - `humor: 'none' | 'dry' | 'witty' | 'playful'`
   - `vocabulary: 'simple' | 'standard' | 'technical' | 'arcane'`

2. `VoiceModel` — describes the structural and stylistic voice:
   - `perspective: 'first' | 'second' | 'third'` (narrative perspective)
   - `sentenceComplexity: 'simple' | 'compound' | 'complex'`
   - `pacing: 'rapid' | 'steady' | 'deliberate' | 'ritualistic'`
   - `rhythmPattern?: string` — optional rhythmic signature description
   - `signaturePhrases?: string[]` — optional recurring phrases

3. `SymbolicAnchor` — binds design-system tokens to identity:
   - `type: 'geometry' | 'color' | 'ratio' | 'archetype' | 'motion'`
   - `name: string` — canonical name (e.g., "golden", "sigil_core")
   - `value: string | number | Record<string, any>` — the raw token value
   - `weight: number` — influence weight (0.0–1.0)
   - `description?: string`

4. `NarrativeConstraint` — shapes how the identity structures stories/explanations:
   - `constraint: string` — the constraint text (e.g., "always begin with a premise")
   - `scope: 'opening' | 'closing' | 'throughout' | 'transition'`
   - `severity: 'suggestion' | 'requirement' | 'imperative'`

5. `MythicIdentity` — the complete mythic schema:
   - `identityId: string` — references SigilIdentity.id
   - `tone: ToneModel`
   - `voice: VoiceModel`
   - `anchors: SymbolicAnchor[]`
   - `constraints: NarrativeConstraint[]`
   - `sigilHash: string` — deterministic hash of this mythic schema
   - `version: number` — schema version (starts at 1)
   - `generatedAt: string` — ISO 8601 timestamp

6. `DEFAULT_NEUTRAL_MYTHIC` — exported constant of type `MythicIdentity`:
   - identityId: "neutral"
   - tone: all fields set to "neutral" or "standard"
   - voice: perspective "third", sentenceComplexity "compound", pacing "steady"
   - anchors: empty array
   - constraints: empty array
   - sigilHash: "neutral"
   - version: 1
   - generatedAt: use a fixed timestamp string

Also create `api/src/types/mythic.test.ts` with:
   - Test that DEFAULT_NEUTRAL_MYTHIC is valid and exported
   - Test that a custom MythicIdentity can be constructed with all fields
   - Test that SymbolicAnchor weight must be between 0 and 1 (runtime check)
  </action>
  <verify>
    <automated>npm test -- --testPathPattern=mythic.test.ts</automated>
  </verify>
  <done>api/src/types/mythic.ts exists with all exported types; DEFAULT_NEUTRAL_MYTHIC is defined; tests pass</done>
</task>
