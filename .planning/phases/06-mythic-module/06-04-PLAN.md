<objective>
Integrate the Mythic Module into the core reasoning pipeline by injecting mythic identity context into Orchestrator system prompts, propagating it through AgentBuilder, and surfacing mythic metadata in API responses.

Purpose: Without this integration, the Mythic Module is an isolated service. This plan wires it into every generation path so that all LLM outputs are automatically shaped by the active identity's tone, voice, and symbolic anchors.
Output: Updated Orchestrator, AgentBuilder, MultiAgentOrchestrator, and ReasonResponse with mythic prompt injection and metadata.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API Request → Controller | Untrusted input enters the system |
| Controller → Orchestrator | Request data crosses into core reasoning |
| Orchestrator → LLM Provider | Prompt crosses to external service |
| LLM Output → mythify | Untrusted text enters rewriting pipeline |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11 | Spoofing | identity_anchor in request | mitigate | IdentityBindingService validates anchor against database; mythic module uses validated identity |
| T-06-12 | Tampering | mythicMetadata in response | accept | Metadata is derived from service state, not user input; tampering would require compromising the service |
| T-06-13 | Repudiation | mythic prompt injection | accept | No audit requirement for prompt content in Phase 6 (audit comes in Phase 8) |
| T-06-14 | Information Disclosure | system prompt leak | mitigate | mythify only transforms the final output text, not the full prompt; prompt remains server-side |
| T-06-15 | Denial of Service | mythify on large outputs | mitigate | All string operations are linear-time; no regex backtracking risks |
| T-06-16 | Elevation of Privilege | neutral identity bypass | accept | Neutral identity is the absence of identity, not a privilege escalation |
</threat_model>
