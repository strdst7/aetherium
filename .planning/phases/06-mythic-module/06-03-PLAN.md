  <action>
Create `api/src/services/mythic-module.ts` with `MythicModuleService` class:

1. Constructor dependencies:
   - `identityBinding: IdentityBindingService`
   - `anchorLoader: SymbolicAnchorLoader`
   - `constraintEngine?: IdentityConstraintEngine` (optional, for advanced mythify)

2. `async generateMythicIdentity(identityId: string): Promise<MythicIdentity>`:
   - If identityId === 'neutral' or empty → return DEFAULT_NEUTRAL_MYTHIC clone
   - Resolve SigilIdentity via identityBinding.resolve(identityId)
   - If not found → return DEFAULT_NEUTRAL_MYTHIC clone
   - If SigilIdentity has `config.mythic` → return it (cached/pre-existing)
   - Otherwise generate a new MythicIdentity:
     - tone: derive from identity.config fields or use heuristics (e.g., if name contains "formal" → formal, else neutral)
     - voice: default to third-person, compound sentences, steady pacing
     - anchors: load from anchorLoader.loadAnchors(), bind to identity.sigilHash
     - constraints: load from anchorLoader.loadConstraints()
     - sigilHash: compute deterministic hash from identityId + anchors JSON (use simple string hash, e.g., murmur or SHA-256 of JSON.stringify)
     - version: 1
     - generatedAt: new Date().toISOString()
   - Return the generated MythicIdentity

3. `async mythify(identityId: string, rawOutput: string): Promise<string>`:
   - Get MythicIdentity via generateMythicIdentity(identityId)
   - Apply tone rewriting rules:
     - If tone.formality === 'ceremonial' → prepend ritualistic opening if missing
     - If tone.vocabulary === 'arcane' → replace common words with elevated synonyms (maintain a small built-in map)
     - If tone.humor === 'dry' → detect and remove exclamation marks, add ironic understatement
     - If tone.emotionalRange === 'stoic' → minimize adjectives, prefer factual statements
   - Apply voice rewriting rules:
     - If voice.perspective === 'first' → convert third-person references to first-person
     - If voice.pacing === 'ritualistic' → insert deliberate pauses (line breaks after key phrases)
     - If voice.sentenceComplexity === 'simple' → break compound sentences into shorter ones
   - Apply symbolic anchor injection:
     - If anchors contain 'golden' ratio → reference "golden proportion" in output if relevant
     - If anchors contain 'sigil_core' → reference "the core" or "central sigil" in output
   - Apply narrative constraints:
     - If any constraint.scope === 'opening' → ensure output begins with appropriate framing
     - If any constraint.scope === 'closing' → ensure output ends with appropriate framing
   - Return the rewritten output

4. `async generateMythicPrompt(identityId: string, basePrompt: string): Promise<string>`:
   - Get MythicIdentity
   - Build system prompt extension:
     - "You are speaking as {identity.name}. Adopt a {tone.formality} tone with {tone.emotionalRange} emotional range. Use {voice.perspective}-person perspective. Pace your response as {voice.pacing}."
     - Add symbolic context: "Your symbolic anchors include: {anchor descriptions}"
     - Add constraints: "Narrative constraints: {constraint descriptions}"
   - Append to basePrompt: `{systemExtension}\n\n{basePrompt}`
   - Return the enhanced prompt

5. `computeSigilHash(identityId: string, anchors: SymbolicAnchor[]): string`:
   - Deterministic hash: sort anchors by name, JSON stringify, prepend identityId, hash with crypto.createHash('sha256').digest('hex').slice(0, 16)
   - Export as static method for testing
