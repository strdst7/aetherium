   - Verify `validationReport.checks` is a non-empty array
   - Verify `validationReport.identityId` matches the requested identity

   - POST `/v1/reason` with strict identity and a prompt likely to generate casual tone
   - Verify response `validationReport` exists
   - If `validationReport.attemptNumber` > 1, verify regeneration occurred
   - Verify final output contains required phrase ("sacred geometry")
   - Verify final output does NOT contain forbidden phrase ("casual")

4. Test: "failure report is returned after max attempts for impossible identity"
   - POST `/v1/reason` with impossible identity
   - Verify response `status` is "failed"
   - Verify response has `failureReport` field
   - Verify `failureReport.attemptCount` is 3 (or equals maxAttempts)
   - Verify `failureReport.safeFallbackMessage` is non-empty
   - Verify `failureReport.violationSummary` is non-empty
   - Verify response `output` equals `failureReport.safeFallbackMessage` (NOT the raw unvalidated output)

5. Test: "multi-agent endpoint includes per-agent validation reports"
   - POST to multi-agent endpoint with standard identity
   - Verify response has `archivist.validationReport`, `sigilKeeper.validationReport`, `narrator.validationReport`
   - Verify all reports have status "passed"

6. Test: "validation metadata includes correct check categories"
   - Inspect `validationReport.checks` array
   - Verify at least one check has `rule.category === "forbidden"`
   - Verify at least one check has `rule.category === "tone"`
   - Verify at least one check has `rule.category === "symbolic"`

7. Test: "processing time remains under latency budget"
   - POST `/v1/reason` with standard identity
   - Verify `response.metadata.processingTimeMs` is under 5000ms (the p99 budget from ROADMAP)
   - Verify validation adds less than 200ms overhead (compare with and without validation)

8. Test: "validation respects skipHalo option"
   - POST `/v1/reason` with `options.skipHalo: true`
   - Verify response does NOT have `validationReport`
   - Verify response status is NOT "failed"

9. Cleanup:
   - Delete test identities after tests
   - Close database connections
