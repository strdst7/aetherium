<task type="auto">
  <name>task 1: create Sovereign Halo type definitions</name>
  <files>api/src/types/halo.ts, api/src/types/halo.test.ts</files>
  <action>
Create `api/src/types/halo.ts` with the following type definitions (use TypeScript interfaces, export all):

1. `ValidationRule` — describes a validation rule being checked:
   - `id: string` — rule identifier (e.g., "forbidden_behavior", "tone_deviation", "symbolic_drift")
   - `name: string` — human-readable name
   - `category: 'forbidden' | 'tone' | 'symbolic' | 'safety'`
   - `weight: number` — importance weight (0.0–1.0), default 1.0

2. `ValidationCheck` — result of a single validation check:
   - `rule: ValidationRule`
   - `passed: boolean`
   - `detail: string` — human-readable result description
   - `confidence: number` — confidence score 0.0–1.0
   - `metadata?: Record<string, any>` — optional extra data (e.g., matched words, deviation score)

3. `ValidationReport` — aggregated validation result:
   - `status: 'passed' | 'failed'` — overall pass/fail
   - `checks: ValidationCheck[]` — all individual checks
   - `passedCount: number`
   - `failedCount: number`
   - `totalCount: number`
   - `confidenceScore: number` — weighted average of check confidences
   - `identityId: string` — the identity this validation was for
   - `validatedAt: string` — ISO 8601 timestamp
   - `attemptNumber?: number` — which regeneration attempt this report belongs to (1-based)

4. `ToneDeviationCheck` (extends ValidationCheck metadata shape):
   - `expectedTone: string` — the expected tone register
   - `detectedTone: string` — heuristic-detected tone in output
   - `deviationScore: number` — 0.0 (perfect match) to 1.0 (complete mismatch)

5. `SymbolicDriftCheck` (extends ValidationCheck metadata shape):
   - `expectedAnchors: string[]` — list of expected anchor concepts
   - `detectedAnchors: string[]` — anchors found in output
   - `missingAnchors: string[]` — anchors not found
   - `driftScore: number` — 0.0 (no drift) to 1.0 (complete drift)

6. `FailureReport` — returned when all regeneration attempts exhausted:
   - `status: 'failed'`
   - `attemptCount: number` — number of regeneration attempts made
   - `violationSummary: string[]` — concise list of persistent violations
   - `safeFallbackMessage: string` — safe message for caller (never contains unvalidated output)
   - `lastValidationReport: ValidationReport` — the report from the final failed attempt
   - `identityId: string`
   - `generatedAt: string` — ISO 8601 timestamp

7. `HaloValidationOptions` — options for validation behavior:
   - `maxAttempts?: number` — default 3
   - `temperaturePenalty?: number` — temperature reduction per attempt, default 0.1
   - `requireSymbolicAnchors?: boolean` — default true
   - `toneTolerance?: number` — deviation threshold before flagging, default 0.5
   - `skipSafetyCheck?: boolean` — default false

Also create `api/src/types/halo.test.ts` with:
   - Test that a valid ValidationReport can be constructed with all fields
   - Test that ValidationReport confidenceScore is computed correctly (weighted average)
   - Test that FailureReport safeFallbackMessage is non-empty
   - Test that HaloValidationOptions defaults are sensible
   - Test that ValidationCheck confidence is between 0 and 1
