  <action>
    Create api/src/services/identity-service.ts implementing the IdentityService class.

    REQUIRED methods and behavior:

    1. `constructor()` — no arguments. Sets `client`, `db`, `collection` to null.

    2. `async connect(mongoUri?: string): Promise<void>`
       - Default URI: `process.env.MONGODB_URI || "mongodb://localhost:27017/aetherium"`
       - Creates MongoClient, connects, gets db, gets collection `"identities"`
       - Creates indexes:
         - `{ identity_id: 1 }` with `unique: true`
         - `{ sigil_hash: 1 }` with `unique: false`

    3. `async disconnect(): Promise<void>` — closes client, nulls out fields.

    4. `async createIdentity(request: IdentityCreateRequest): Promise<SigilIdentity>`
       - Generate `identity_id` using `id_` prefix + `crypto.randomBytes(16).toString("base64url")`
       - Generate `sigil_hash` using deterministic SHA-256:
         - Build object with keys in alphabetical order: `allowed_behaviors`, `constraints`, `forbidden_behaviors`, `mythic_signature`, `name`, `voice`
         - Include only keys present in the request (filter out undefined)
         - JSON.stringify the sorted object
         - `crypto.createHash("sha256").update(canonicalJson).digest("hex")`
       - Set `version: 1`, `created_at: new Date().toISOString()`, `updated_at: same as created_at`
       - Initialize `versions: []` (empty on creation)
       - Insert into collection
       - Return the created identity

    5. `async getIdentityById(identity_id: string): Promise<SigilIdentity | null>`
       - Query by `identity_id` field (NOT `_id`)
       - Return null if not found

    6. `async listIdentities(): Promise<SigilIdentity[]>`
       - Return all documents from collection as array
       - Sort by `created_at` descending

    7. `async updateIdentity(identity_id: string, request: IdentityUpdateRequest): Promise<SigilIdentity>`
       - Fetch existing identity. If not found, throw `Error("Identity not found")`
       - Build snapshot of current state (clone of current identity excluding `identity_id`, `sigil_hash`, `version`, `created_at`, `updated_at`, `versions`)
       - Append to `versions` array: `{ version_number: current.version, sigil_hash: current.sigil_hash, updated_at: current.updated_at, snapshot }`
       - Merge request fields into current identity (only defined fields)
       - Recompute `sigil_hash` with the same canonicalization logic as create
       - Increment `version` by 1
       - Set `updated_at: new Date().toISOString()`
       - Update document in collection (query by `identity_id`)
       - Return updated identity

    8. `async getVersionHistory(identity_id: string): Promise<IdentityVersion[]>`
       - Fetch identity by `identity_id`
       - If not found, throw `Error("Identity not found")`
       - Return `identity.versions` array

    9. `private generateSigilHash(data: Record<string, any>): string`
       - Extract the deterministic hash logic described above

    Import requirements:
    - `import { MongoClient, Db, Collection } from "mongodb"`
    - `import crypto from "crypto"`
    - `import { SigilIdentity, IdentityCreateRequest, IdentityUpdateRequest, IdentityVersion } from "../types/identity"`
