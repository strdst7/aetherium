  <action>
    Create api/src/controllers/identity.ts.

    Export a class `IdentityController` with a constructor that accepts `IdentityService`.
    Export a factory function `createIdentityRouter(service: IdentityService): express.Router` that returns an Express router.

    Controller methods (all async, returning the response object directly):

    1. `async register(req: { body: IdentityCreateRequest }): Promise<{ status: 201; body: SigilIdentity }>`
       - Validate the request body using the validation rules below.
       - On validation failure: throw `new AetheriumError(ErrorCode.INVALID_REQUEST, "Validation failed", { errors: [...] })`.
       - On success: call `service.createIdentity(req.body)` and return `{ status: 201, body: identity }`.

    2. `async getById(req: { params: { id: string } }): Promise<{ status: 200; body: SigilIdentity } | { status: 404; body: ProblemDetails }>`
       - Call `service.getIdentityById(req.params.id)`.
       - If null: throw `new AetheriumError(ErrorCode.IDENTITY_NOT_FOUND, \`Identity '${req.params.id}' not found\`, { instance: req.originalUrl })`.
       - On success: return `{ status: 200, body: identity }`.

    3. `async list(_req: any): Promise<{ status: 200; body: { identities: SigilIdentity[]; count: number } }>`
       - Call `service.listIdentities()`.
       - Return `{ status: 200, body: { identities, count: identities.length } }`.

    Validation logic (private method `validateCreateRequest`):
    - `name`: required, typeof === "string", length >= 1 && <= 128, matches `/^[a-zA-Z0-9\s\-]+$/`
    - `voice`: required, typeof === "string", length >= 1 && <= 256
    - `constraints`: if present, must be Array, length <= 50, each item typeof === "string" && length >= 1 && <= 512
    - `mythic_signature`: if present, typeof === "string" && length <= 1024
    - `allowed_behaviors`: if present, must be Array, length <= 100, each item typeof === "string" && length >= 1 && <= 256
    - `forbidden_behaviors`: if present, must be Array, length <= 100, each item typeof === "string" && length >= 1 && <= 256
    - Collect ALL validation errors into an array before throwing. Each error object: `{ field: string, message: string, code: string }` where code is one of: "MISSING_FIELD", "INVALID_FIELD_TYPE", "FIELD_OUT_OF_RANGE", "INVALID_FORMAT".

    Router wiring in `createIdentityRouter`:
    - `router.post("/identity/register", async (req, res, next) => { try { const result = await controller.register(req); res.status(result.status).json(result.body); } catch (e) { next(e); } })`
    - `router.get("/identity/:id", async (req, res, next) => { ... })`
    - `router.get("/identity", async (req, res, next) => { ... })`

    Import requirements:
    - `import express from "express"`
    - `import { IdentityService } from "../services/identity-service"`
    - `import { SigilIdentity, IdentityCreateRequest } from "../types/identity"`
    - `import { AetheriumError, ErrorCode } from "../middleware/error-handler"`
    - `import { ProblemDetails } from "../types/api-contracts"`
